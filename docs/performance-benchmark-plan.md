# 변환 성능 테스트와 혼합 실행 계획 (2026-10-12)

사용자가 승인한 비교 테스트와 선택적 사진·영상 혼합 실행을 구현한다.

1. 기본 분리 실행을 유지하는 mixed_media_workers 설정을 추가한다. 기존 작업 서명과 예상시간 이력은 기본값에서 유지한다.
2. 혼합 실행은 사진/영상별 제한으로 빈 슬롯을 채운다. 계획 파일명/SEQ, 취소/저널 게시 안전 정책을 유지한다.
3. 환경설정에서 Source의 영상/사진 샘플과 실제 Target를 사용한다. 영상 앞 10초 두 번을 순차/동시 비교한다. 사진 네 번을 추가하여 혼합 전후의 같은 작업량을 비교한다.
4. Target에 독립 TemporaryDirectory를 생성하고 테스트 종료/취소 시 자신의 파일만 정리한다. 원본, 기존 결과, 작업 저널과 예상시간 이력은 수정하지 않는다.
5. 현재 인코더/품질/해상도 설정을 사용한다. 시험에서는 크기 제한/작아질 때만 출력 정책을 제외한다. 10% 이상 빨라지고 성공한 경우에만 더 높은 동시성을 추천한다. 추천값은 사용자가 적용하고 환경설정 확인으로 저장한다.
6. 백그라운드 테스트, 중단, 실패 안내, 샘플 부재, 기본값 호환, 동시 실행/취소/SEQ 및 실제 FFmpeg 검증을 수행한다.
7. 버전 1.0.1.20과 관련 문서를 갱신하고 EXE를 다시 빌드한다. origin은 반영하지 않는다.
