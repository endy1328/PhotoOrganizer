## 2026-10-11 일시정지/중단·프로세스 창 / 1.0.1.12

- 사용자는 일시정지/재개 및 작업 중단 둘 다 요청하고 현재 파일 완료 후 멈추는 기준으로 진행을 승인했다. 기존 DONE/PENDING 저널과 이어서 실행을 보존하며 즉시 인코딩 취소는 구현하지 않는다.
- UI 응답을 위해 QThread worker와 queued 진행 신호를 사용한다. 작업 중 편집·상세 조회·저장·종료를 잠그고 자동 저장 및 저널 복원을 차단한다. 중단 미리보기는 기존 결과를 보존하고 실행은 완료 기록과 나머지 PENDING을 유지한다.
- 마지막 파일까지 완료했다면 정지 요청이 있어도 정상 완료하며 대기하지 않는다. 일시정지 중 중단은 대기를 해제한다. 제어 상태는 처리 설정이나 계획 서명에 포함하지 않는다.
- 영상 창 숨김은 공통 subprocess 옵션으로 Windows CREATE_NO_WINDOW/숨김 STARTUPINFO와 stdin=DEVNULL을 적용한다. 완료 시 창 활성화를 요청하지 않으며 작업 오류는 모달 대신 상태/오류 목록으로 표시한다. 사용자가 요청한 설정/파일 선택 대화상자는 기존 방식을 유지한다.

### 2026-10-10 - 휴대폰 동일 이름 처리 설정, 기본 덮어쓰기

- 사용자 요청으로 휴대폰의 같은 폴더/같은 이름 파일 처리 정책을 환경설정에서 선택한다. overwrite/skip/rename을 저장하고 기본값은 overwrite다. 1.0.1.0의 고정 건너뛰기 정책을 대체한다. 기존 설정의 항목 없음/잘못된 값도 사용자 요청에 따라 overwrite로 해석한다.
- 기존 폴더는 재사용하며 내용 해시/크기 일치로 중복을 판정하지 않는다. 새 이름은 확장자를 보존해 `_copy0001`부터 빈 이름을 찾는다. 동일 이름 복수 객체/폴더 충돌은 자동 교체하지 않는다.
- overwrite는 신규 임시 객체 전송·확인→기존 정확한 객체 ID를 백업 이름으로 보존→신규 최종 이름 변경/확인→해당 백업 파일만 비재귀 삭제한다. 이름 변경 미지원이면 기존 파일 선삭제로 우회하지 않는다. 실패 시 복구를 시도하고 연결 해제 등으로 복구 불가면 남은 파일 이름을 안내한다.
- 취소는 교체 시작 전에 적용하며 교체 시작 후에는 복구/최종 확인을 마무리한다. PC 원본/휴대폰 다른 파일/폴더는 삭제하지 않는다. 이 정책은 휴대폰 전송에만 적용하고 일반 정리 파일 처리 정책은 유지한다.
- 4자리 버전 `1.0.1.1 (2026-10-10)`로 보강한다.

### 2026-10-10 - 영상 메타데이터 출력과 모델 태그 보강

- unique attempt 임시 파일을 자기 범위에서만 정리하며 게시 전에 기존 경로를 재확인한다. 복구에서는 덮어쓰지 않고 초기 실행만 기존 OVERWRITE 정책을 유지한다. 게시 완료와 DB 완료 사이 실패는 UNCERTAIN/IN_PROGRESS로 막는다.
- PC 공통 Windows global mutex로 새 버전 실행 폴더 간 미디어 처리를 직렬화한다. 기존 버전/외부 변경에는 매 단계 검사를 적용한다. 복구 계획은 RUN/WAIT/KEEP/BLOCK을 표시하고 실제 후속 실행 전에 재검증한다.
- 표준 sqlite3/ctypes를 사용하여 외부 의존성을 추가하지 않는다. 영상 프레임별 이어하기와 휴대폰 전송 재개는 이번 범위에서 제외한다.
