# 미리보기 클릭별 상세 정보 구현 계획

> 작업자는 작은 단계로 구현하고 독립 검토를 통해 결과를 확인한다. 기존 미커밋 변경과 읽기 전용 .git를 보존하여 현재 폴더에서 진행한다.

**Goal:** 원본 경로/대상 경로/새 파일명 클릭에 따라 하단 썸네일과 메타정보를 같은 파일 기준으로 전환한다.
**Architecture:** MainWindow의 미리보기 선택 기준과 경로 helper를 추가한다. 기존 이미지 로드와 메타정보 표시를 공유하고 미생성/누락 상태를 명확히 표시한다. 파일 처리와 작업 저장 형식은 유지한다.
**Tech Stack:** PySide6, unittest, PyInstaller.
