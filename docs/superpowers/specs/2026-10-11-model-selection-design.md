# 모델별 처리 선택 설계 — 2026-10-11

사용자가 승인한 위치: 미리보기 탭 안, 파일 표 바로 위. 모델별 가로 체크박스는 공간이 부족하면 줄바꿈한다. 정규화와 영상 추론 후의 모델명을 기준으로 사진/영상 건수를 보여준다. UNKNOWN도 독립 선택 가능하고 기본은 전부 선택한다.

선택 해제된 행은 표에 회색으로 남고 처리 방식은 제외로 표시한다. 제외 항목은 Target 복사/이동, 모바일 출력, 삭제 리뷰에서 빠진다. 모델 선택은 현재 미리보기에만 유지하고 새 미리보기는 모두 선택한다. 입력/설정이 바뀐 미리보기의 제외 선택을 묵시적으로 무시하고 전체 실행하지 않는다. 재미리보기를 요구한다.

전체 원본을 읽고 모델 추론을 끝낸 뒤 필터를 적용하므로 제외 모델 사진도 추론 근거가 될 수 있다. 선택된 파일만 날짜별 공통 SEQ를 다시 부여하며 수동 파일명은 유지한다. 재계산 출력 충돌은 표에 표시하고 실행 시 건너뛰며 오류 기록한다. 모든 모델을 해제하면 실행을 막고 안내한다. 실행 중/후에는 모델 선택을 잠그며 새 미리보기를 통해 변경한다. 휴대폰 복사 창은 기존 Target 전체 output_ 검색 동작을 유지한다.

코어는 PreviewItem.included와 PreviewBundle.selection_applied 및 추출된 media_items를 보관하고 set_selected_models(bundle, selected_models)로 재계산한다. 기존 소비자는 포함 기본값 True로 호환한다. 버전 1.0.1.3 (2026-10-11), 테스트/관련문서/EXE 동시 갱신.
