# 모바일 복사 영상 용량 제한

사용자가 설명된 설계를 승인했다. PC 변환/원본에는 영향을 주지 않고 실제 output_ 파일을 USB로 복사할 때만 적용한다.

- 환경설정: 용량이 큰 동영상 복사 제외, 기본 해제. 기준 기본 500 MB, 정수 1..1000000. 1 MB=1000000 bytes.
- 기준과 같은 크기 또는 더 큰 MP4/MOV/M4V/AVI/MKV/WMV 제외, 대소문자 무관. 사진/기타 파일에는 적용하지 않는다.
- 휴대폰과 경로 선택 방식은 기존과 같다. 폴더 목록과 선택 합계에 전송 파일 수/용량 및 제외 수, 상단에 적용 기준을 표시한다.
- 복사 시작 및 업로드 전 실제 크기 재확인. 제외 영상은 SIZE_EXCLUDED 결과와 크기/기준 이유를 로그에 남긴다. 휴대폰 기존 같은 이름 파일을 유지한다.
- 제한 활성 시 전송할 파일이 없는 출력/하위 폴더는 생성하지 않는다. 제한 해제 시 기존 빈 폴더 복사 동작을 유지한다.
- 수집/파일 크기 판정은 워커에서 처리한다. 복사 중 변경 파일의 크기를 재확인하되 외부 프로세스와의 완전한 동시 수정 방지는 보장하지 않는다.
- 신규 설정 키 phone_video_limit_enabled / phone_video_limit_mb. TOML 및 이전 JSON에서 잘못된 형식은 기본값으로 정규화한다.
- 검증: 경계 크기, 사진, 확장자, 중첩/빈 폴더, 기존 파일과 모든 충돌 정책, 크기 변경, 설정/표시/로그와 전체 회귀. 실제 휴대폰 쓰기 검증은 별도로 기록한다.
