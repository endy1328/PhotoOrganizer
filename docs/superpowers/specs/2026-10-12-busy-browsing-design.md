# 작업 중 조회와 현재 파일 표시

## 범위

미리보기/실행/복구 실행 중 조회용 UI를 사용한다. 표 선택/스크롤/탭/이미지/상세/메타정보/도킹/환경설정 조회는 허용하고 계획·파일·작업을 바꾸는 동작은 잠근다. 사용자 원격 push 요청은 이번 변경의 자동 push 허용으로 확장하지 않는다.

## 정책

- 환경설정은 실제 실행에 제출한 request/job settings의 독립 스냅샷을 보여주는 비모달 조회 전용 창이다. 저장/적용/초기화/편집을 막고 스크롤·값 확인·닫기를 허용한다. idle 환경설정은 기존 편집 동작을 유지한다.
- 바쁜 동안 파일명 편집/모델 제외/경로·모드 변경/새 작업·저장·열기/휴대폰 전송/삭제는 잠근다. 삭제 표 체크도 별도로 잠근다.
- 상세 조회는 읽기 전용이다. 캐시 메타정보는 활용하고 무거운 이미지/영상/메타정보 읽기는 단일 조회 worker에서 처리한다. 최신 선택만 적용하며 파일 변경/삭제/미생성은 정상 안내로 처리한다. Qt pixmap과 위젯 변경은 GUI 스레드에서만 한다.
- OperationControl은 실제 시작한 파일의 활동을 스레드 안전하게 보관한다. 파일/단계 enter, update, finally exit로 구성하며 미시작 대기 항목은 표시하지 않는다. 불변 snapshot으로 조회하고 기존3인자 완료 progress와 SEQ는 유지한다.
- UI는100ms 주기로 현재 작업 파일과 단계를 표시한다. 병렬 사진은 최대4개를 함께 표시하고 전체 경로는 툴팁으로 제공한다. 종료/실패/중단 후 표시를 정리한다. 일시정지/중단 안내와 완료율은 유지한다.

## 검증

설정 스냅샷 불변, 조회에 따른 작업dirty/서명 불변, UI응답/늦은 조회 결과 방어, 실제 시작/종료/병렬 활동 및 pause/stop 회귀를 검증한다. 작은 창 UI, 전체 회귀, 문서와1.0.1.16(2026-10-12) EXE를 확인한다.
