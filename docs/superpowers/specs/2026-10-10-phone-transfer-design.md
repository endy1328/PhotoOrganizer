# USB 휴대폰 복사 설계

2026-10-10 사용자 승인: 선택한 휴대폰 경로 바로 아래에 PC Target의 output_날짜_모델명 폴더와 모든 파일/하위 폴더를 복사한다.

Windows + Android USB 파일 전송(MTP)을 지원한다. 기존 정리/모바일 출력 생성과 독립된 모바일로 복사 버튼을 제공하고 기존 Target에도 사용한다. iPhone과 ADB/USB 디버깅은 이번 범위에 포함하지 않는다.

휴대폰 새로고침, 기기 선택, 저장소/폴더 탐색, 새 폴더, 날짜별 출력 목록(기본 전체 선택), 파일 수/용량, 전송 시작/취소 및 파일별 결과를 표시한다. 탐색과 전송은 작업 스레드에서 수행한다.

Target 아래 output_ 폴더의 실제 파일을 재귀 수집하고 원래 output_ 폴더명과 상대 경로를 유지한다. 링크/정션은 따라가지 않고 앱 작업용 임시 폴더는 제외한다. PC 파일과 휴대폰 기존 파일을 삭제하거나 덮어쓰지 않는다. 기존 동일 이름 파일은 건너뛰되 동일 내용으로 간주하지 않는다. 재시도는 파일 단위이며 이미 존재하는 파일은 건너뛴다.

Windows WPD backend에서 기기 및 객체 ID로 탐색하고 신규 객체 스트림 쓰기/Commit/사후 크기 조회를 수행한다. COM은 전용 worker 소유로 유지한다. 취소는 청크 경계에서 요청하며 즉시 종료를 보장하지 않는다. 실패/취소/완료 미확인을 구분하고 내용 해시 검증이라고 표현하지 않는다.

가상 backend로 재귀 구조, 충돌, 취소, 연결 실패, 크기 불일치, UI 작업 종료를 테스트한다. Windows WPD 초기화/기기 나열 및 배포 리소스를 확인한다. 실제 휴대폰이 없으면 실제 전송 검증 미실시를 명시한다. 관련 문서와 4자리 버전/수정날짜를 함께 갱신하고 EXE를 빌드한다.
