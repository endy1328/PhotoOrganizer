# 작은 화면과 원격 접속 UI / 1.0.1.14

상태: 구현 및 최종496개 회귀(494통과/2skip)·한국어 화면/배율·1.0.1.14 EXE 검증 완료. 사용자 지시에 따라 UI 수정은 로컬에만 유지하고 사전snapshot 이후 추가push하지 않았다.

## 목표와 근거

- 기존 UI는 한국어10pt에서 1024×650 요청 시 최소 높이854로 늘어나고 목록 viewport35px에 불과했다. 상단의 긴 요약 줄바꿈과 여러 입력 행, 하단 상세 영역의 최소 크기·접기 불가가 원인이다.
- 실제 창의 가용 너비·높이를 기준으로 목록을 우선 확보한다. FHD와1204×1032를 기본 검증하고1024×650 및 배율150/200%의 논리 좌표에서도 컨트롤에 접근할 수 있게 한다.

## 배치와 디자인

- 경로 두 행을 기본으로 유지하고 디바이스명/처리 방식/안내는 추가 옵션으로 접는다. 작업 저장·열기 버튼은 메뉴로 정리하고 처리 상태는 간결하게 표시한다.
- 작업 버튼은 유연한 배치로 접근 가능하게 유지한다. 출력 설정 요약은 한 줄/전체 툴팁으로 표시한다.
- 모델 선택은 펼침/접기를 제공하고 체크 목록이 길어지면 제한된 내부 공간에서 스크롤한다. 개별 선택과 기존 모델 추론/매핑 동작을 보존한다.
- 넓은 화면에서는 목록 왼쪽·상세 오른쪽, 좁은 화면에서는 목록 위·접을 수 있는 상세 아래로 전환한다. 상세 정보/메타정보는 탭으로 공간을 공유한다. 목록은 최소한의 가시 영역을 우선한다.
- 선택 파일 기준(원본/대상/새 파일명), 파일명 편집, UNKNOWN 빨간 배경, 처리 중 UI 잠금 및 일시정지/중단을 보존한다.
- 맑은 고딕/시스템 한국어 글꼴과 작은 공통 간격, 중립 배경·파란 강조색을 사용한다. 큰 장식 카드나 불필요한 애니메이션은 사용하지 않는다. 키보드 포커스와 비활성 상태는 명확하게 표시한다.
- 열 표시 선택 및 패널/열 크기 기억은 화면 선호 설정으로 분리하고 실행 계획 서명에 영향을 주지 않는다. 화면 변경 시 저장된 창 위치/크기를 현재 사용 가능한 영역에 맞춘다.

## 검증과 범위

- Qt 오프스크린에서 창 크기/배치/목록 높이/접기·펼치기/메뉴·버튼 접근/상세 기준 및 처리 제어 회귀를 검증한다. 합성 데이터만 사용하고 실제 사용자 파일을 변환하지 않는다.
- 전역 작업 잠금은 제품 그대로 유지하고 테스트 프로세스만 별도 mutex를 사용한다.
- 엔진·SEQ·파일 게시·휴대폰 복사 정책은 변경하지 않는다. 관련 문서와4자리 버전/수정날짜를 최신화하고 EXE를 빌드한다.
