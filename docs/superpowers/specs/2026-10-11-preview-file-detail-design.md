# 미리보기 클릭 열에 따른 파일 상세 정보

상태: 사용자 승인 후 구현·전체413개 회귀(411통과/2skip)·GUI·EXE 배포 검증 완료. 버전 1.0.1.11 (2026-10-11).

## 요구사항과 현재 상태

미리보기 표의 원본 경로/대상 경로/새 파일명 클릭에 따라 하단 사진·영상 미리보기와 메타정보의 기준 파일을 변경한다. 현재 미리보기는 원본 경로와 사전 추출한 원본 metadata_entries로 고정되어 있다. 실행 결과는 원본/대상/모바일 출력 경로 클릭 전환을 이미 지원한다.

## 권장 동작

| 클릭 열 | 기준 파일 |
|---|---|
| 원본 경로 | source_path |
| 대상 경로 | target_path |
| 새 파일명 | target_path (변경 후 파일명을 가진 대상 파일) |

다른 열은 직전 기준을 유지하고 최초 기준은 원본이다. 경로·상세 기준을 하단에 명시한다. 새 파일명은 기존 이름 변경 편집 기능과 병행한다.

썸네일과 메타정보는 동일한 기준 파일을 사용한다. 대상이 없으면 대상 경로와 파일 없음 상태를 표시하고 메타정보/기존 이미지 내용을 비운다. 원본 정보로 자동 대체하지 않는다. 대상이 있으면 실제 대상 파일을 읽는다. 원본이 이동되어 없어진 경우에도 원본 클릭은 없음으로 표시한다. 원본의 사전 추출 정보를 사용하는 경우에도 현재 존재 여부를 확인한다.

기존 상세 패널과 표 레이아웃을 유지한다. 클릭 때마다 창을 띄우는 방식보다 기존 패널 전환이 비교에 유리하다. 프로그램 파일 처리/작업 저장 형식/휴대폰 복사 정책은 변경하지 않는다. 상세 기준 선택은 현재 UI 상태로 관리한다.

## 구현과 검증 계획

- 미리보기 클릭 이벤트와 원본/대상 기준 상태, 공통 기준 경로 helper를 추가한다.
- 이미지·영상 썸네일 및 메타정보를 같은 helper로 연결한다.
- 다른 행에서도 클릭 열 기준이 맞게 갱신되며 새 파일명 편집 뒤 최신 target_path를 사용한다.
- 원본/대상의 서로 다른 메타정보, 사진/영상, 동일 행 열 전환, 대상 미생성/누락, 수동 이름 편집, 기존 실행 결과 전환을 검증한다.
- 동작 변경 문서 5종 및 네 자리 버전/수정날짜를 갱신하고 EXE를 다시 빌드한다.
