# output_ 생성 용량 제한

사용자가 승인한 설계: 사진과 영상 모두 변환 후 실제 결과 파일의 크기가 기준 이상이면 output_ 최종 파일로 저장하지 않는다. 일반 분류 폴더의 정리 작업과 기존 모바일 복사 제한은 독립이다.

- 환경설정 모바일 출력에 생성 제외 체크박스와 기준 용량을 추가한다. 기본 해제/500 MB, 1..1000000 정수 MB, 1 MB=1000000 bytes.
- 임시 파일로 변환한 뒤 >= 기준이면 임시 파일을 정리한다. 기존 output_ 파일은 삭제하거나 교체하지 않는다. 신규 제외 파일의 빈 output_ 폴더는 생성하지 않는다.
- 기준 미만이면 기존 최종 저장/촬영 시각 적용을 따른다. 수동 파일명은 기존 충돌 방지 정책을 유지한다.
- 용량 제외는 출력 SIZE_EXCLUDED 결과와 크기/기준 이유 및 INFO 로그로 표시하고 다음 항목을 계속 처리한다. 일반 파일 정리는 성공으로 처리하며 copy/move와 삭제 리뷰의 기존 정책은 유지한다.
- 영상이 원본보다 작을 때만 생성 옵션으로 먼저 건너뛴 경우 SKIPPED를 유지한다. 해당 경우 완성 출력이 없어 용량 판정을 하지 않는다.
- 임시 변환은 필요하므로 변환 시간/임시 디스크 사용을 줄이는 기능이 아니다. 미리보기 시 실제 변환 크기는 확정하지 않는다.
- 설정 키 mobile_output_limit_enabled/mobile_output_limit_mb, 이전 설정 미지정 시 기본값. 모바일 복사 제한과 별개로 저장한다.
- 경계 크기/사진영상/성공실패 임시 정리/기존 파일/수동 파일명/이동/후속 파일 진행/설정/UI와 전체 회귀 및 독립 검토 후 EXE 빌드한다.
