# 실행 확인과 진행 상세 설계

사용자는 실행 전 예상시간 확인창, 실행 중 핵심 표시와 필요할 때 여는 도킹 진행 패널을 승인했다.

- 실행 전 유효 미리보기의 포함 항목으로 사진/영상 수, 복사/이동, 사진 병렬 수, 영상 인코더, 예상시간 범위와 초기 추정 안내를 표시한다. 취소는 실행 checkpoint/미디어 변경 전에 반환한다. 자동 미리보기가 필요하면 먼저 준비하며 준비만으로 변환을 시작하지 않는다.
- 재개/재시도는 기존 복구 계획 검토를 유지하고 실제 실행 가능한 항목만 시간 확인에 포함한다. 완료된 단계는 추정에서 제외한다.
- 기본 진행 영역에 완료/전체, 경과시간, 예상 남은 시간, 현재 파일명과 단계를 표시한다. 일시정지 대기는 남은 시간 보정에서 제외한다.
- 진행 상세는 기본 숨김인 좌/우/하단 도킹 패널이다. 버튼과 보기 메뉴로 열고 native 분리/닫기를 제공한다. 창 표시가 변환을 제어하거나 포커스를 자동으로 가져오지 않는다. 활성 파일/단계/파일별 경과와 최근 최대50개 결과를 제공한다. 전체 결과는 기존 실행 결과에 남긴다.
- Qt 없는 추정 모델은 저장된 크기/영상 길이 및 출력 설정을 사용하며 파일을 다시 스캔하거나 영상 probe를 하지 않는다. 자료 부족 시 넓은 범위와 초기 추정 안내를 제공한다. 완료 실행의 보정 비율만 실행 폴더의 버전 있는 제한된 JSON에 원자적으로 저장한다. 실패/중단 기록은 성능 보정에 넣지 않는다.
- 변환 성공/실패는 활동 소멸만으로 추측하지 않고 실제 결과/저널 단계 상태를 읽어 thread-safe bounded 결과 이벤트로 전달한다. 완료율/SEQ/미디어 정책은 유지한다.
- 관련 문서와 버전1.0.1.17(2026-10-12), EXE를 함께 검증하며 origin에는 push하지 않는다.
