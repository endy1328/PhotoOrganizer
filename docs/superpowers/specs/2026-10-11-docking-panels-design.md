# 이미지·상세 독립 도킹 패널

## 사용자 요구

주요 영역의 크기를 마우스로 조절하고 이미지 프리뷰와 상세 정보는 각각 표시/숨김을 선택한다. 패널 제목을 드래그해 왼쪽·오른쪽·아래에 붙이며 별도 창으로 분리할 수도 있다.

## 설계

- QMainWindow 중앙에는 기존 경로/작업 버튼/목록을 두고 이미지와 상세 정보는 독립 QDockWidget으로 만든다.
- 각 패널의 기본 제목과 닫기 버튼, native separator를 제공한다. 허용 도킹 위치는 좌우하단이며 상단에는 경로/작업 영역을 유지한다.
- 보기 메뉴에서 두 패널의 표시 상태와 기본 배치 복원을 제공한다. 상세의 선택 정보/메타정보 탭과 클릭 기준은 유지한다.
- 첫 기본 배치는 넓은 창 오른쪽, 좁은 창 아래쪽이다. 사용자의 위치/크기 변경은 이후 자동 재배치로 덮어쓰지 않는다. 작은 화면에서 목록 공간을 확보하는 자동 접기는 사용자 표시 의도와 구분한다.
- view_preferences.json에 versioned Qt saveState/base64, 독립 표시 상태를 저장한다. 설정/작업 서명 및 파일명/SEQ에는 영향을 주지 않는다.
- 이전 JSON의 details_visible 값을 두 패널 표시 상태로 이전하고 깨진 저장값은 무시한다. 다른 화면에서 floating 창을 복원할 때 사용 가능한 화면 안으로 제한한다.

## 범위와 검증

변환/메타정보/원본 안전 정책 변경이나 외부 라이브러리 추가는 없다. 도킹/분리/독립 표시/복원/작은 창/바쁨 상태를 Qt 테스트하고 전체 회귀 후 버전1.0.1.15 EXE를 만든다. 실제 원격 접속 조작은 사용자 환경에서 별도 확인한다. origin push는 하지 않는다.
