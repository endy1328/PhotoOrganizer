# 미리보기·실행 일시정지/중단 및 영상 프로세스 창 숨김

상태: 사용자 일시정지·재개와 중단 모두 및 현재 파일 완료 후 멈춤 승인. 구현·회귀 검증 후 배포1.0.1.12 (2026-10-11).

## 현재 상태와 원인

preview/execute/resume를 UI 스레드에서 직접 호출하고 진행 이벤트 때 processEvents를 호출한다. ffmpeg.run이 진행 중일 때는 UI 이벤트를 처리하지 못한다. metadata.py(ffprobe)/video_output.py(ffmpeg)/video_thumbnail.py(ffmpeg)에 Windows CREATE_NO_WINDOW가 없다. phone_wpd.py의 PowerShell 호출에는 이미 적용되어 있다. 콘솔 창 숨김과 UI 응답 개선은 각각 필요하다.

## 권장안: 파일 경계에서 일시정지/중단

- 처리 버튼 줄에 일시정지/재개 토글과 중단 버튼을 둔다. 미리보기·실행·이어서 실행·실패 재시도에 공통으로 적용한다. 대기/종료 상태에는 비활성화한다.
- 일시정지는 현재 파일 처리와 단계 완료 기록을 마친 뒤 다음 파일 시작 전 대기한다. 상태는 정지 요청 중→일시정지로 표시한다. 재개는 같은 작업의 다음 파일부터 진행한다. 정지 요청 대기 중 재개를 눌러 요청을 해제할 수도 있다.
- 중단은 현재 파일 처리 완료 후 남은 파일을 시작하지 않고 작업을 종료한다. 일시정지 중 중단하면 즉시 대기를 해제한다. 완료 파일/이동 정책/저널 증거는 유지하며 나머지 PENDING은 나중에 이어서 실행한다. 긴 영상은 현재 변환이 끝나야 실제 정지/중단된다.
- 미리보기 중단은 새 불완전 결과로 기존 미리보기를 교체하지 않는다. 미리보기 재실행으로 다시 시작한다. 미리보기 일시정지/재개는 현재 메타정보 조회 후 다음 파일에서 대기한다. 스캔도 작은 순회 단위마다 요청을 확인한다.
- 실제 정지/중단은 오류로 표시하지 않고 사용자 요청 상태로 표시한다. 남은 파일이 있어 실제 중단했다면 전체 완료/미리보기 준비 완료 문구로 덮지 않는다. 마지막 파일까지 완료했다면 정상 완료하며 불필요한 정지 대기에 들어가지 않는다. 파일 게시·원본 제거·DB 기록을 강제로 끊지 않는다.

## 작업 구조 및 포커스

- Qt worker 스레드에서 엔진 작업을 실행하고 progress/result/error는 Signal로 UI 스레드에 전달한다. 중지/재개는 thread-safe 상태만 변경한다. worker에서 위젯/processEvents/메시지 창을 호출하지 않는다.
- 기존 동기 호출 UI 테스트/흐름과 재진입을 고려하여 작업 완료를 기다리는 Qt 이벤트 루프와 worker 수명을 명확하게 관리한다. busy 동안 새 작업·열기·삭제·휴대폰 복사·창 종료를 잠그는 기존 정책을 유지한다.
- 공통 외부 프로세스 옵션으로 Windows CREATE_NO_WINDOW와 STARTUPINFO 숨김을 ffprobe/ffmpeg 모든 호출에 적용한다. stdin은 DEVNULL로 닫고 출력은 기존 파이프로 수집한다. shell=True/cmd 래핑은 사용하지 않는다. Windows 외 환경에는 Windows 전용 옵션을 넘기지 않는다.
- 처리 완료 시 창을 앞으로 올리거나 activateWindow를 호출하지 않는다. 시작 시 기존 창 표시와 실제 사용자가 요청한 대화상자는 유지한다. 일반 처리 실패 알림은 앱 상태/오류 목록으로 전달하여 백그라운드 작업 중 포커스를 강제 이동하지 않는다.

## 대안과 한계

현재 복사/영상 인코딩까지 즉시 중단하려면 취소 가능한 Popen/복사 청크, 자식 종료 확인, 해당 시도 임시 파일 정리, 취소 단계의 저널 상태/재개 규칙을 별도로 설계해야 한다. 강제 종료를 IN_PROGRESS→PENDING으로 바꾸는 방법은 금지한다. 현재 파일을 마치고 멈추는 방식은 완료 증거와 기존 이어서 실행을 그대로 사용한다. ffmpeg 프로세스 자체의 OS 일시정지 방식은 환경 의존성과 상태 위험 때문에 권장하지 않는다.

## 검증과 산출물

미리보기/실행/복구 각각 정지 요청·재개·중단, 일시정지 중 중단, 첫 파일/마지막 파일, 기존 미리보기 보존, 이동 원본/성공 파일 보존, 중단 저장/열기/이어하기, worker 동안 UI 응답, 호출별 Windows 창 숨김 옵션, 비Windows 분기, 백그라운드 완료 시 activateWindow 없음, 실제 ffmpeg 프로세스와 GUI를 검증한다. 문서5종/네 자리 버전/수정날짜/EXE를 함께 갱신한다. 기존 파일 처리 범위와 모바일 전송 취소는 유지한다.
