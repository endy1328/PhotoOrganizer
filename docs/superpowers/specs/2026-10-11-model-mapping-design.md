# 모델명 별칭 매핑 설계

사용자 승인: 원본 모델명→출력 별칭을 환경설정에서 등록하며 적용 범위를 선택한다. 기본은 새 파일명+분류 폴더, 다른 선택은 새 파일명만이다. output_ 폴더는 분류 폴더의 이름을 따른다.

원본 모델과 촬영 메타데이터 및 추론은 유지한다. 매핑은 추출/추론/기존 모델 정규화 이후 출력 생성에 한 번만 적용한다. 여러 원본에 같은 별칭을 등록할 수 있고 매핑 체인은 적용하지 않는다. 모델 체크의 선택 단위는 원본 모델이며 표시에는 원본→별칭을 함께 보여준다. UNKNOWN 매핑도 원본 미확인 근거와 행 색상은 유지한다.

등록 표는 추가/수정/삭제를 지원한다. 원본은 기존 모델 그룹과 동일한 대소문자/구분자 정규화로 매칭하고 중복 원본을 거절한다. 별칭은 Windows 파일명/폴더명 구성요소로 검증하며 한글 등 Unicode를 허용하고 내부 공백은 밑줄로 저장한다. 빈 값, 경로문자, 제어문자, 예약 이름, 끝의 점은 거절한다. 직접 수정한 전체 파일명은 모델 선택 재계산에서 유지한다.

설정은 기존 config.toml에 저장한다. 누락된 설정은 빈 매핑/모두 적용 기본값을 따른다. 잘못된 매핑은 다른 정상 설정을 잃지 않도록 로드에서 제외하되 UI 및 저장 단계에서는 검증 오류를 보여준다. 같은 폴더의 임시 파일에 먼저 쓰고 교체해 저장 실패로 기존 설정을 잃지 않도록 한다. 기존 미리보기의 매핑/범위가 바뀌면 재미리보기를 요구해 옛 대상 또는 전체 모델의 묵시적 실행을 막는다. 같은 Source/Target에서 매핑 변경으로 재미리보기할 때 기존 수동 파일명은 새 매핑 분류 폴더에 일괄 복원한다. 충돌은 파일명을 바꾸지 않고 CONFLICT로 표시한다. 일반 재미리보기의 초기화 정책은 유지한다.

날짜별 공통 SEQ는 유지한다. 기존/선택 재계산의 파일명과 모바일 경로 충돌 정책을 유지하고 여러 원본이 같은 폴더로 합쳐지는 경우도 SEQ를 공유한다. 원본과 이전 출력은 자동 변경하지 않는다. 1.0.1.5 (2026-10-11) 배포.
