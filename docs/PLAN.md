## 작업 운영 흐름

- 작업 시작 시 남은 작업을 확인하고 전체 목록을 정리한다.
- 필요하면 계획 서브에이전트를 생성해 실행 계획을 먼저 만든다.
- 병렬 가능한 업무는 기능 단위로 나누어 서브에이전트에 배분한다.
- 각 작업이 끝날 때마다 검증 서브에이전트가 결과를 점검한다.
- 진행상황 전담 서브에이전트가 단계, 완료 항목, 남은 작업, 리스크를 주기적으로 보고한다.
- 메인 에이전트가 순서와 우선순위를 조율하고 최종 내용을 정리한다.
- 특별한 이슈가 없으면 사용자에게 묻지 않고 최적의 판단으로 진행한다.
- 작업 종료 후에는 관련 문서를 반드시 현행화한다.

### 1. 요구사항 구체화

- 현재 남은 작업을 목록화하고, 기능별 책임 범위를 정리한다.
- 필요하면 계획 서브에이전트를 통해 세부 실행 계획을 생성한다.
- 사진 입력 파일 범위와 지원 확장자 정의
- 영상 입력 파일 범위와 지원 확장자(`MP4`, `MOV`, `M4V`, `AVI`, `MKV`, `WMV`) 정의
- 메타데이터 우선 사용 규칙 정의
- 메타데이터 부재 시 fallback 규칙 정의
- 사진과 영상의 일시 추출 우선순위 정의
- 영상 fallback 모델명 추출 규칙 반영
- 파일명 fallback 패턴 우선순위 반영
- 영상 메타 시각에 timezone 정보가 있으면 로컬 시간대로 변환한 뒤 정렬/파일명 생성에 사용하도록 정의
- 복사 기본, 이동 선택 지원, 동일 파일명이라도 확장자/용량/실제 메타데이터가 모두 같으면 덮어쓰기 허용, 그 외 충돌은 SEQ 증가 정책 반영
- 날짜 디렉토리 아래에 `YYYYMMDD_모델명` 디렉토리를 추가
- SEQ는 같은 날짜의 모델/UNKNOWN 디렉토리 전체에서 `0001`부터 공유하고 촬영 일시 순서로 부여하며 날짜 변경 때만 초기화
- 삭제는 사용자 비포/애프터 리뷰 후 수행하는 절차로 정의
- 미리보기는 변경 전/후 경로, 추출 근거, 오류 예상을 포함하도록 정의
- 미리보기는 신규 생성/덮어쓰기/SEQ 증가 처리 방식도 함께 표시하도록 정의
- 사용자가 상단에서 입력한 디바이스명은 값이 있을 때 메타데이터/파일명 추론보다 우선 적용하도록 정의
- 파일명 fallback은 `IMG_20240327170722454` 같은 연속형 시각도 `HHMMSS`까지 읽도록 유지
- 일반 출력 파일 확장자는 소스 파일의 대소문자를 그대로 유지하도록 정의
- 공백/밑줄/하이픈만 다른 모델명 표기는 같은 canonical key로 그룹핑하고 대표 표기를 선택하도록 정의
- 모든 그리드는 헤더를 마우스로 직접 조절할 수 있도록 공통 정책으로 유지
- 로그는 프로그램 실행 폴더 `logs`에 저장하고 최근 30일 보관으로 정의
- 오류 파일은 건너뛰고 로그 기록으로 정의
- `1.1`에서는 정리 완료 후 `YYYYMMDD_MODEL/output_YYYYMMDD_MODEL` 하위에 모바일 출력본을 추가 생성하도록 정의
- 사진 모바일 출력 대상 포맷은 `JPG/JPEG/PNG/HEIC`로 정의
- 동영상 모바일 출력은 `MP4(H.264/AAC)` 재인코딩으로 정의
- 모바일 출력 기본값은 사용으로 정의
- 모바일 출력 기본 설정값은 사진 최대 가로 `3000`, JPEG 품질 `75`, 동영상 최대 가로 `1280`, 품질 `balanced`로 정의
- 원본 가로가 기준보다 작으면 원본 크기를 유지하도록 정의
- 모바일 출력 생성 실패 시 전체 실행 실패로 처리하도록 정의
- 메인 화면 버튼 줄 오른쪽에 `환경설정` 버튼과 모바일 출력 요약 상태를 표시하도록 정의
- 모바일 출력 `JPG/JPEG`는 EXIF/ICC를 보존하도록 정의
- 모바일 출력 `PNG`는 PNG 텍스트 메타데이터와 ICC를 보존하도록 정의
- 모바일 출력 `HEIC`는 현재 `JPG`로 저장하고 디코더가 제공한 EXIF/ICC를 보존하도록 정의
- `YYYYMMDD_HHMMSS_MODEL_SEQ4` 형태 재입력 시 마지막 `SEQ4`는 모델명에서 제거하도록 정의
