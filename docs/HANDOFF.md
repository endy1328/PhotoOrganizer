# HANDOFF

## 현재 상태 요약

- V1 기본 구현은 동작 가능한 상태다.
- 현재 사용자 표시 버전은 `1.0.0.3`이고, 모바일 출력 기능 요구사항과 기본 정책이 반영되어 있다.
- `README.md`는 최종 사용자 가이드만 담고, 검증 하네스/운영 메모는 이 문서와 스크립트가 담당한다.
- 코어 엔진, 메타데이터 추출, 파일명 fallback, 영상 모델명 fallback, PySide6 UI, 설정 저장, 로그 저장, 삭제 리뷰 흐름이 반영되어 있다.
- 대상 경로는 `날짜/날짜_모델명/파일` 구조를 사용한다.
- 디바이스명 수동 입력, 모델명 대소문자 보존, 진행상황 표시, 이미지 미리보기, 조건부 덮어쓰기, 충돌 표시가 반영되어 있다.
- 일반 출력 파일 확장자는 소스 파일의 대소문자를 그대로 유지한다.
- 모바일 출력은 사진과 동영상을 모두 생성하고, 사진은 `JPG/JPEG/PNG/HEIC` 메타데이터 보존 정책, 동영상은 `MP4(H.264/AAC)` 재인코딩 정책이 반영되어 있다.
- 영상은 `ffmpeg`가 있으면 상세 패널 왼쪽에서 썸네일 프레임 미리보기를 표시하고, 같은 도구로 동영상 모바일 출력도 생성한다.
- 미리보기 상세 패널 오른쪽은 `선택 항목 정보`와 `메타정보` 2단 구조로 표시된다.
- 문서는 현재 구현 상태 기준으로 갱신되어 있다.

## `1.1` 확정 사항

- 개발 브랜치 권장명: `feature/v1.1-mobile-output`
- 모바일 출력 디렉토리 구조:
  - `.../YYYYMMDD_MODEL/output_YYYYMMDD_MODEL`
- 기본값:
  - `enabled = true`
  - 사진 `max_width = 3000`
  - 사진 `jpeg_quality = 75`
  - 사진 작은 원본은 원본 크기 유지
  - 동영상 `max_width = 1280`
  - 동영상 `quality = balanced`
  - 동영상은 원본보다 작아질 때만 저장
- 대상 포맷:
  - 사진 `JPG/JPEG/PNG/HEIC`
  - 동영상 `MP4(H.264/AAC)`
- 실패 정책:
  - 모바일 출력 단계 실패 시 전체 실행 실패
- UI 방향:
  - 버튼 줄 오른쪽 `환경설정` 버튼
  - 메인 화면 모바일 출력 요약 상태 표시
  - 하단 상세 영역에 모바일 출력 예정 경로 표시

## `1.1` 현재 구현 상태

- 설정 저장 구조에 모바일 출력 필드가 추가되었다.
- 메인 화면 버튼 줄 오른쪽에 `환경설정` 버튼과 요약 상태 라벨이 추가되었다.
- 미리보기는 사진/동영상 모두 모바일 출력 경로를 계산한다.
- 실행 시 사진은 이미지 리사이즈/메타 보존 저장을 수행하고, 동영상은 `ffmpeg` 기반 `MP4(H.264/AAC)` 재인코딩을 수행한다.
- 모바일 출력 JPG/JPEG는 EXIF/ICC를 보존하고, PNG는 텍스트 메타데이터/ICC를 보존한다.
- 정리된 결과 파일명 `YYYYMMDD_HHMMSS_MODEL_SEQ4`를 다시 읽을 때 마지막 `SEQ4`는 모델명에서 제거한다.
- 현재 확인 환경 기준 테스트 57개 통과, 13개 skip가 확인되었다.
- 미리보기 상세 메타정보 UI와 메타 요약 전달 테스트가 추가되었다.
- 아직 남은 것은 실제 HEIC 샘플 기반 저장 검증과 GUI 재확인이다.

## 현재 알려진 제한 사항

- 이 작업 환경에서는 사용자 `.venv`를 항상 직접 재현하지 못할 수 있다.
- 사용자 환경 기준 `.venv`는 Python `3.13.13`으로 재구성되었다.
- 현재 확인 환경 기준 `unittest` 57개 통과, 13개 skip가 최신 확인 상태다.
- 사용자 환경 `.venv` 기준 최신 상세 수치는 별도 재확인 전까지 고정하지 않고, 현재 확인 환경 기준 `57개 통과, 13개 skip`를 공통 기준으로 본다.
- 실제 GUI 상호작용과 샘플 파일 검증은 계속 사용자 환경 확인이 필요하다.

## 구현상 주의사항

- Source와 Target은 서로 포함 관계가 아니어야 한다.
- 설정값은 실행 폴더의 `config.toml`에 저장되며, 시작 시 자동으로 불러온다.
- 파일 시스템 시간은 촬영 일시 판단에 사용하지 않는다.
- 영상 모델명 메타데이터가 없으면 같은 디렉토리 사진 기준 `±5분` 규칙을 사용한다.
- 후보가 없거나 충돌하면 `UNKNOWN`을 사용한다.
- 디바이스명/모델명은 파일명 안전 문자만 남기고 대소문자는 보존한다.
- 대상 경로는 `YYYY년 / YYYY년 MM월 / YYYYMMDD / YYYYMMDD_모델명 / 파일명` 구조다.
- SEQ는 같은 모델명 디렉토리 안에서만 `0001`부터 증가하고, 순서는 `captured_at` 오름차순이다.
- 미리보기와 실행은 같은 입력값이면 같은 경로 계획을 공유한다.
- 삭제 리뷰는 휴지통 이동 기준이며 자동 영구 삭제로 떨어지지 않도록 방어 로직을 넣어두었다.
