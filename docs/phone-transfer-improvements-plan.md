# 모바일 복사 경로 저장 및 사용성 개선 계획

**목표:** 휴대폰 폴더 위치를 저장/불러오기하고 기존 복사 규칙을 유지하며 화면·진행 표시·재시도·원격 조회를 개선한다.

**구조:** 경로 이름과 기기 이름은 별도 JSON에 저장한다. 연결 세션의 객체 ID는 저장하지 않고 WPD worker에서 경로를 재탐색한다. UI 상태, 재시도 검증, 전송 정책은 각각 별도 모듈로 분리한다.

**환경:** Python/PySide6, 기존 WPD C# helper. 현재 작업 디렉토리의 기존 미반영 변경을 보존하며 origin 반영은 하지 않는다.

- [x] 1. `phone_locations.py`: 원자적 JSON 저장, 여러 위치 등록/삭제, 실제 이름으로 경로 탐색, 없거나 중복된 경로는 오류. 저장/재연결/손상 JSON/서로 다른 기기 테스트를 먼저 실패시키고 구현했다.
- [x] 2. `phone_transfer_dialog.py`: 저장 위치 선택 목록 및 저장·불러오기·삭제. 경로 불러오기는 읽기 작업이며 자동 폴더 생성/전송은 하지 않는다. 첫 단계 테스트·독립 검토 후 나머지 단계로 진행했다.
- [x] 3. `phone_view_preferences.py`와 dialog: 세 목록 QSplitter, 컬럼 폭/순서 조절, 창·분할·컬럼 설정 JSON 보존, 작은 화면 검증.
- [x] 4. dialog/WPD: 취소 후 마지막 진행률 유지, 파일 수·용량 진행률/속도·남은 시간, 전송 단계·응답 대기 안내. 진행 중 조회/스크롤은 허용하고 전송 대상 변경은 잠근다.
- [x] 5. `phone_retry.py`와 dialog: 실패/취소 파일만 재시도. 성공·건너뜀·용량 제외·완료 미확인은 자동 재시도 대상에서 제외한다. 현재 기기/경로/원본 상태를 다시 확인한다.
- [x] 6. `phone_transfer.py`: 폴더 조회 소요 시간 기록과 정책 판정용 목록 재사용. WPD 생성·교체 직전의 최종 충돌 검증은 유지하고 실기 속도 개선은 측정 전 단정하지 않는다.
- [x] 7. 전체693개 회귀(691통과·2skip)·독립 검토·최종 소스 EXE 빌드와 내장30모듈/실제 worker 검증. README/TASKS/PLAN/DECISIONS/VALIDATION 갱신. 네 자리 버전1.0.1.25와 한국 수정날짜2026-10-12 유지.

각 단계의 실패 테스트와 통과 결과는 VALIDATION에 최종 기록한다. 실제 Android USB 재연결·취소·연결 끊김·속도 측정은 사용자 환경 후속 검증으로 구분한다.
