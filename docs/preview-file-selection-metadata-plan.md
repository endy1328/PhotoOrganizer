# 개별 파일 제외와 원본 모델명 기록 구현 계획

**목표:** 승인된 설계에 따라 개별 제외와 백업 가능한 원본 모델명 수정을 제공한다.
**구조:** 선택/재계획은 engine, 원본 기록/복구는 독립 서비스, UI는 비동기 작업 연결만 담당한다.
**환경:** Python/PySide6, 프로젝트 전용 ExifTool 동봉. 기존 변경 보존, origin 반영 없음.

**현재 상태:** 1.0.1.26(2026-10-13) 구현·독립 검토·전체 회귀·GUI 렌더·배포 검증 완료.

- [x] 1. 선택 코어: models/engine/job_store/resume_models/model_selection에 개별 선택과 모델 필터 상태 분리. TDD 후 교집합/SEQ/수동 이름/구작업 로드/실행 불변 검증을 구현했다.
- [x] 2. 원본 기록 서비스: metadata_writer.py와 metadata.py에 도구 탐색·모델 태그 기록/읽기·보존 검증·전체 백업/원자교체·내용 지문/저널/복원을 구현했다. JPG/JPEG/PNG/MP4/MOV/M4V 활성화, HEIC 미활성. 합성/복사 샘플을 사용하며 사용자 원본은 테스트하지 않는다.
- [x] 3. UI: 기존 논리0~8열 보존/처리 논리9열 기본 맨 앞 배치, 체크/다중 선택 메뉴, 원본 모델명 편집창·worker·복원, 같은 폴더 재읽기/영상 재추론·선택/수동 이름 보존·캐시 갱신·저장과 실행 시작 후 잠금을 구현했다.
- [x] 4. 도구 동봉: 공식 ExifTool13.59 Windows x64·라이선스·출처·ZIP/파일 SHA256 고정, 설치/오프라인 검증 스크립트·숨김 실행·PyInstaller 포함·미지원 형식 안내. 시스템 PATH는 변경하지 않는다.
- [x] 4a. 강제 종료 안전 상태: 원본 쓰기/복원 전 최근/활성 작업 파일에 차단 checkpoint 강제 저장, 저장 실패 시 쓰기 금지. 성공 재계획 후 새 checkpoint, 실패/로드 후 재미리보기 필수. 일반 자동저장 해제와 별개로 안전 checkpoint를 수행한다.
- [x] 5. 독립 검토·관련/전체 회귀·작은 화면 확인·문서 현행화·1.0.1.26 빌드/내장 코드/실제 worker/ExifTool 검증.

원본 테스트는 작업 폴더 합성/복사 샘플만 사용한다. 앱 소유 보관 폴더를 미리보기와 모바일 스캔에서 제외한다. 실행 시작된 계획/원본은 수정하지 않는다. 실패/중단 복구와 내용 변경 검출을 검증하고 검증하지 못한 쓰기 형식은 활성화하지 않는다.
